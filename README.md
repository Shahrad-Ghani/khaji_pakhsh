# خاجی پخش — KHAJI Frontend Demo V3

این پروژه **نسخه سوم طراحی نمایشی Frontend** وب‌سایت خاجی پخش است؛ با Next.js و TypeScript، طراحی فارسی RTL و پالت Clean White & Gold. فایل لوگوی اصلی بدون بازطراحی استفاده شده است. هیچ Backend، پرداخت آنلاین یا دیتای تجاری واقعی ارائه نمی‌شود.

## مهم‌ترین تغییرات V3

- **Header دو‌ردیفه** طبق رفرنس ارسالی مشتری: لوگوی اصلی و عنوان «خاجی پخش» بزرگ‌تر در سمت راست، جست‌وجوی نمایشی در مرکز، شماره فروش در سمت چپ، نوار ناوبری جداگانه زیر آن. آیکون سبد خرید/حساب کاربری عمداً اضافه نشده است.
- **زیرمنوی Hover/Focus برای دسته‌بندی‌ها و برندها** در دسکتاپ، با لینک به مسیرهای واقعی ۸ دسته و ۱۳ برند. در موبایل منوهای بازشونده لمسی دارند.
- عرض محتوا افزایش یافته و فاصله افقی `container` از ۲۵px به ۱۵px (۴۰٪ کمتر) رسیده؛ Hero نیز عریض‌تر شده است.
- **نشان طلایی ارسالی** جایگزین خط تزئینی ۶ عنوان سکشن اصلی شده است.
- **اعداد ۰۱/۰۲/۰۳ مراحل خرید حذف شدند** و FAQ با انیمیشن نرم باز و بسته می‌شود.
- **CTA انتهای صفحه سفید/عاجی/طلایی شده** و لوگوی اصلی در آن نمایش داده می‌شود. فوتر تیره مطابق قبل حفظ شده است.
- جمله هشدار زیر جدول قیمت و عبارت «نسخه نمایشی وب‌سایت — اطلاعات نمونه» از هدر حذف شده‌اند؛ قیمت‌ها همچنان داده نمایشی هستند، و توضیح مربوط به نمونه‌بودن داده‌ها در عنوان و caption دسترس‌پذیر جدول باقی مانده است.
- Hero تصویری بازبینی‌شده بدون نوشته KHAJI روی تجهیزات، از فایل `KHAJI_Hero_No_Equipment_Logos_HQ.webp` جایگزین شد.
- تمام تغییرات دستی CSS کارفرما درباره موقعیت `category-body` و `hero-copy`، بزرگ‌نمایی تصاویر و وسط‌چین Hero دقیقاً در بخش `User-approved V2 manual positioning` حفظ شده‌اند. برای موبایل Override ریسپانسیو جداگانه وجود دارد.

## اجرای پروژه در Windows / VS Code

۱. فایل ZIP سورس را استخراج کن و پوشه `khaji-nextjs-v3` را با VS Code باز کن.

۲. **فونت‌ها:** فایل‌های IRAN Family جزو ZIP خروجی نیستند. اگر در پروژه V2 فونت‌ها را نصب کرده‌ای، چهار فایل WOFF2 را از پوشه شخصی `public/fonts` همان پروژه به `public/fonts` در V3 کپی کن؛ یا `assets.zip` اصلی خودت را **کنار پوشه پروژه** قرار بده تا `predev` به‌صورت خودکار فونت‌ها را نصب کند. لطفاً مجوز فونت خودت را رعایت کن.

۳. در ترمینال **Command Prompt** داخل VS Code:

```cmd
npm install
npm run dev
```

۴. آدرس `http://localhost:3000` را باز کن. Next.js تغییرات CSS/TSX را معمولاً بعد از `Ctrl + S` بدون راه‌اندازی مجدد نمایش می‌دهد.

برای تست نصب نهایی:

```cmd
npm run typecheck
npm run build
```

## پیش‌نمایش HTML بدون npm

اگر فقط می‌خواهی ظاهر را ببینی، پس از نصب فونت‌ها فایل `preview/index.html` را در مرورگر باز کن. این پیش‌نمایش مستقل ۸ صفحه آزمایشی دسته و ۱۳ صفحه آزمایشی برند نیز دارد. برای آزمایش واقعی Routing و ساختار Next.js، از `npm run dev` استفاده کن.

## مسیرهای مهم

- `src/components/SiteHeader.tsx` — هدر بزرگ، dropdownهای برند و دسته، منوی موبایل
- `src/components/FAQAccordion.tsx` — FAQ روان و دسترس‌پذیر
- `src/app/page.tsx` — ساختار یازده‌بخشی Homepage
- `src/app/globals.css` — CSS پایه، مقادیر مورد تأیید V2، تنظیمات V3 و Media Queryها
- `src/content/site.ts` — دسته‌ها، برندها، قیمت‌های صرفاً نمونه، شماره تماس
- `public/images/ui/khaji-gold-emblem.png` — نماد طلایی ارسالی برای تیترها
- `public/images/hero/khaji-hero-products.webp` — تصویر اصلاح‌شده Hero

## وضعیت بررسی

فایل‌های جدید از نظر syntax JSX/TypeScript بررسی شده‌اند؛ پیش‌نمایش مستقل در مرورگر Chromium با عرض‌های ۱۴۴۰ و ۳۹۰ پیکسل رندر شد و عدم Overflow افقی، فونت‌ها، dropdown دسکتاپ، آکاردئون موبایل و بازشدن FAQ کنترل شدند. **Build نهایی Next.js همچنان در این محیط تأیید نشده**؛ بعد از نصب پکیج‌ها، `npm run build` و بررسی نسخه Next.js روی سیستم خودت ضروری است.
